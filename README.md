# Daily Reflection AI Agent 

A deterministic, stateful AI Agent designed for employee end-of-day reflection. This project uses **Knowledge Engineering** to guide users through psychological reframing without the need for probabilistic LLMs.

## 🚀 Overview
This tool helps employees process their workday by navigating a 25-node decision tree. It evaluates three key axes:
1. **Locus of Control:** Shifting from a "Victim" to a "Victor" mindset.
2. **Growth Orientation:** Moving from routine tasks to intentional learning.
3. **Radius of Impact:** Expanding focus from self-tasks to team success.

## 🛠️ Project Structure
- `runner.js`: The "Brain" of the project. A stateful controller that processes the tree and tracks user signals.
- `tree.json`: The "Knowledge Base." Contains 25+ deterministic nodes (Questions, Reflections, Bridges, and Summaries).
- `Report.pdf`: Technical documentation explaining the psychological frameworks (Rotter, Dweck, Maslow) used.

## ⚙️ Requirements
- [Node.js](https://nodejs.org/) (v14 or higher)
